# 🎯 Coolify Quick Commands

## Post-Deploy Command (w ustawieniach aplikacji Coolify)

```bash
bash /app/coolify-post-deploy.sh
```

## Ręczne uruchomienie (w terminalu Coolify)

```bash
# Wykonaj wszystkie kroki post-deploy
bash /app/coolify-post-deploy.sh

# Lub pojedyncze komendy:
npx prisma migrate deploy
npx prisma generate
```

## Sprawdzenie statusu

```bash
# Sprawdź połączenie z bazą
npx prisma db execute --stdin <<< "SELECT 1;"

# Sprawdź migracje
npx prisma migrate status

# Sprawdź wersję Prisma
npx prisma --version
```

## Naprawa problemów

```bash
# Zresetuj migracje (OSTROŻNIE!)
npx prisma migrate reset

# Wygeneruj Prisma Client na nowo
npx prisma generate

# Sprawdź schemat
npx prisma db pull
```
